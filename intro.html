Overview

这个整合包是什么

它不是一个只换了颜色的世界，而是一套完整的冥界玩法框架。地形由原版主世界噪声生成， 建筑、生物、地表和指令则围绕阴司主题重新组织。

独立维度

wcnm:underworld，出生点鬼门关，y=81，无岩顶，可自由飞行。

原版噪声地形

主世界式丘陵、山谷与洞穴，不再使用 WFC 台地；只保留一个冥界群系。

50 座冥筑

鬼门关、奈何桥、阎罗殿、酆都城、十八层狱……每座建筑都有发光告示牌。

多样地表与生物

冥土、魂砂砾、骨壤、血苔、魂石、阴草；游魂、鬼火、阴兵与冥犬。

Installation

导入 PCL2

推荐使用桌面上的 DeepUnderWorld-beta-2.5.2.mrpack。PCL2 会自动安装 Minecraft 26.3、Fabric Loader 和整合包模组。

方式 A · 在线版 .mrpack 推荐

文件约 127 KB，导入时需要联网，由 Modrinth 下载模组。适合网络正常的情况。

  • 下载 DeepUnderWorld-beta-2.5.2.mrpack
  • 直接拖进 PCL2 窗口，或使用「版本列表 → 导入整合包」
  • 等待依赖下载完成，不要中途关闭 PCL2

方式 B · 离线版 .mrpack / .zip 无网络

离线版约 41 MB，所有模组已经打包在里面，不需要在线下载。

  • 优先使用 -offline.mrpack
  • PCL2 兼容性异常时再使用 -offline.zip
  • 导入方式与在线版相同

确认 Java 25

打开 PCL2 → 设置 → Java，选择 Java 25。Minecraft 26.3 不能使用 Java 17 或 Java 21 启动。

把 .mrpack 拖进 PCL2

也可以点击 PCL2 的「版本列表」→「导入整合包」，选中文件。PCL2 会识别 Modrinth 格式。

等待安装完成

在线版需要下载模组；离线版会直接解压。安装完成后，版本列表中会出现 Deep Under World beta-2.5.2。

分配内存并启动

建议分配 4–6 GB 内存。不要把所有内存都给 Minecraft，否则 Windows 和 PCL2 会不稳定。

第一次启动

进入游戏后新建世界。旧存档不会重新生成地形；想体验 beta-2.5.2 的新地表，请创建新世界。

注意
在线版导入失败时，通常是网络无法访问 Modrinth 或启动器缺少代理。换用离线版即可绕过模组下载。
旧版本
不要在旧版本目录里直接覆盖 mods。请让 PCL2 新建 beta-2.5.2 实例；旧版本可以保留，确认新版本可启动后再删除。
First Steps

第一次进入冥界

主世界出生后，先拿到引魂灯，或者直接使用管理员指令进入。

进入方式

在聊天栏输入：

/wcnm tp

你会落在出生点鬼门关：(0.5, 81, 0.5)。这里是一块灵魂块平台，没有岩顶。

返回主世界：

/wcnm return
提示
不要在冥界使用 /tp 0 0 0 或 0 255 0；前者在地层内，后者在天空。用 /wcnm tp 最稳。

引魂灯使用方式

  • 普通右键方块：把引魂灯放置成一盏灯，亮度 15。
  • 右键空气：在冥界与主世界之间传送。
  • 潜行 + 右键方块：不放置，直接传送。
  • 返回阳间：会先加载目标区块并寻找安全落点，不会把你放进虚空。

合成：4 个哭泣的黑曜石 + 1 个灵魂灯笼。

新建世界

推荐超平坦以外的主世界类型；冥界维度独立生成，不受主世界地形类型限制。

旧存档

旧版本已经生成过的冥界区块不会重写。需要新地表时，换一个新世界或探索未生成区域。

权限

单人游戏默认拥有权限。服务器中需要 OP 或等级 2 以上权限才能使用 /wcnm find 和 /wcnm ls。

Commands

指令速查

所有查询类指令都需要管理员权限。绿色坐标可以点击传送，[复制] 可以复制坐标。

指令作用说明
/wcnm tp进入冥界出生点 (0.5, 81, 0.5)；仅玩家
/wcnm return返回主世界安全落点，不会掉进虚空；仅玩家
/wcnm find查找最近冥筑默认半径 256 格；只输出最近一座
/wcnm find <半径>旧式最近冥筑半径 1–4096；如 /wcnm find 300
/wcnm find radius <半径>列出半径内所有冥筑1–4096，按距离排序；最多显示 200 条，点击坐标传送
/wcnm find structure <结构>定位指定结构搜索半径 8192；英文 ID，支持 Tab 补全
/wcnm find biome <群系>定位群系搜索半径 6400；冥界目前只有 wcnm:underworld
/wcnm ls查看当前区块群系、地表高度、河流/湖泊、区块内冥筑；需要权限等级 2
/wcnm kit发放建造材料引魂灯、冥石、冥石砖、雕纹冥石、幽冥灯、彼岸花
/wcnm tud effects off关闭冥界雾/暗色滤镜夜视下不再粉红；默认已关闭
/wcnm tud effects on开启冥界特效重新启用雾效
/wcnm tud visibleDistance <8-512>设置个人雾距只影响自己，服务端同步到客户端
/wcnm tud visibleDistance reset恢复默认雾距只影响自己

结构 ID 示例

  • ghost-gate · 鬼门关
  • naihe-bridge · 奈何桥
  • fengdu-city · 酆都城
  • reincarnation-well · 轮回井
  • blood-pool · 血池

也支持 Ghost Gate、ghost_gate、wcnm:fengdu_city 或编号 12。

查找示例

/wcnm find radius 500
/wcnm find structure fengdu-city
/wcnm find biome underworld
点击传送
聊天栏里的绿色坐标可以直接点击传送到对应建筑；旁边的 [复制] 会复制 x y z，方便发给朋友或粘贴到指令里。
World & Creatures

地形、地表与生物

冥界不是无限重复的灵魂块。地形、地表材质和生物都被重新配置过。

地形规则

  • 使用原版主世界 NoiseBasedChunkGenerator，有丘陵、山谷和洞穴。
  • 只生成 wcnm:underworld 一个群系，没有海洋或原版河流群系。
  • 湖泊按约 5000×5000 格一个候选点稀疏生成。
  • 河流只存在于 |x|,|z| ≤ 1000，边界前 90 格平滑淡出。
  • 河流水面固定在同一高度 y=48；地形深处会形成带天然顶盖的地下暗流，低洼处才露出水面。

地表材质

  • 灵魂块：基础地表，带国风鬼面纹样。
  • 冥土 / 魂砂砾 / 骨壤：低饱和度的土壤和砂砾斑块。
  • 血苔：暗红苔藓，形成局部低地。
  • 魂石：带幽蓝魂脉的小型岩石露头。
  • 阴草 / 彼岸花：地表装饰植物。

自定义生物

游魂

wcnm:wandering_soul

被动漂浮灵体，围绕玩家缓慢游荡。

/summon wcnm:wandering_soul

鬼火

wcnm:ghost_wisp

更小、更快的幽蓝光点，适合做氛围。

/summon wcnm:ghost_wisp

阴兵

wcnm:ghost_soldier

敌对近战亡灵，生命值较高，会主动攻击玩家。

/summon wcnm:ghost_soldier

冥犬

wcnm:underworld_hound

快速地面猎食者，会从远处扑向玩家。

/summon wcnm:underworld_hound
生存提示
阴兵和冥犬会主动索敌。夜晚、洞穴或建筑内部更危险；如果只想看风景，可以用和平模式，或把生成器关闭在配置中调整。
刷怪蛋
四种生物都有对应刷怪蛋，统一放在创造模式的 Underworld / 冥界 分类中，可以直接取出使用。

JourneyMap

JourneyMap 小地图

beta-2.5.2 已用 JourneyMap 替代 Xaero's Minimap，功能更完整，操作更接近常见地图模组。

打开地图

默认按 J 打开全屏地图。小地图默认显示在屏幕角落。

路径点

在全屏地图上右键创建路径点；死亡点会自动记录，方便找回掉落物。

洞穴模式

JourneyMap 支持洞穴/地表视图切换，适合在冥界洞穴和建筑内部导航。

按键冲突
如果 J 被其他模组占用，打开「选项 → 控制 → 按键绑定」，搜索 JourneyMap 后重新设置。
Atmosphere

雾效、亮度与画面

beta-2.5.2 的默认环境光已调高到 0.55，雾距 224。正常探索不需要夜视。

如果画面仍然偏暗

  • 确认没有开启「阴间特效」：/wcnm tud effects off
  • 检查是否启用了光影；Complementary 的夜晚/洞穴效果可能再次压暗画面。
  • 在视频设置中调高亮度，或使用夜视。
  • 不要在旧版本中测试亮度；beta-2.5.2 才包含最新的环境光调整。

雾距指令

/wcnm tud visibleDistance 128
/wcnm tud visibleDistance reset

雾距只影响自己的客户端，不会改变服务器或其他玩家的画面。

Troubleshooting

常见问题

先确认版本是 beta-2.5.2，再按下面的顺序排查。

PCL2 导入后没有出现版本

完全关闭 PCL2 再重新打开，然后查看「版本列表」。如果仍然没有，检查导入时是否选择了正确的 .mrpack 文件，以及 PCL2 是否是最新版本。

启动时报 Java 版本错误

Minecraft 26.3 需要 Java 25。在 PCL2 的「设置 → Java」中选择 Java 25；不要选择 Java 17、Java 21 或系统自带的旧 Java。

在线版导入时卡住或缺少模组

在线版需要访问 Modrinth。网络不稳定时请改用离线版 -offline.mrpack；它已经包含全部 47 个模组，不依赖在线下载。

进入冥界后看不到建筑，或者地形还是旧样子

旧存档已经生成过的区块不会自动重写。请创建新世界，或前往从未加载过的区域。然后用 /wcnm find radius 500 查找附近的冥筑。

引魂灯放出来是紫色/黑色方块或没有模型

beta-2.5.2 已重绘引魂灯的方块贴图，修复了使用物品图标作为方块贴图导致的渲染问题。请确认启动的是 beta-2.5.2，而不是 2.4.1 或更早版本。已经放置的引魂灯在更新后会自动使用新贴图。

引魂灯把我放进虚空

beta-2.5.2 的返回逻辑会先加载目标区块、读取真实地表高度，并检查头部空间。如果仍然出现异常，请记录主世界出生点坐标和版本号，并提供日志。

世界生成时卡顿

冥界使用完整主世界噪声并叠加建筑、河流、湖泊后处理，首次生成区块时会有短暂卡顿。可以降低渲染距离、关闭光影、分配 4–6 GB 内存；不要使用过高的模拟距离。

小地图不是 JourneyMap / 同时出现两个小地图

beta-2.5.2 只包含 JourneyMap。如果同时看到 Xaero's Minimap，说明你启动的是旧版本实例，或手动复制了旧 mods。请使用 beta-2.5.2 实例，并检查 mods 文件夹中是否还有 xaerominimap。

游戏里太暗，或者夜视下全是粉红

先执行 /wcnm tud effects off。如果仍然暗，检查光影和视频亮度设置。beta-2.5.2 的基础环境光已经提高；旧版本没有这些调整。

服务器里 /wcnm find 没有反应

查询指令需要 OP 或权限等级 2。让服主给你权限，或使用管理员账号执行。生存玩家仍然可以使用引魂灯和普通传送。
